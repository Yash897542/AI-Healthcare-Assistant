# AI Healthcare Assistant using Hugging Face & Prompt Engineering

## Project Overview

This project demonstrates an AI healthcare assistant built using the
Hugging Face Transformers library and the Qwen2.5-0.5B-Instruct model.

The project explores different prompt engineering techniques to improve
the structure, relevance, and reliability of generated responses.

## Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Qwen2.5-0.5B-Instruct
- Google Colab

## Tasks Covered

1. Hugging Face Healthcare Chatbot
2. Role-Based Prompt Engineering
3. Few-Shot Prompting
4. Chain-of-Thought Prompt Design
5. Structured JSON Output
6. Hugging Face Model Comparison
7. Prompt Optimization and Hallucination Reduction
8. Role-Based Healthcare Assistant — Bonus

## Files

- `AI_Healthcare_Assistant_Code.ipynb` — Complete implementation and experiments
- `AI_Healthcare_Assistant_Report.ipynb` — Project report

## Model

The project uses:

`Qwen/Qwen2.5-0.5B-Instruct`

The model was selected because its relatively small size makes it
suitable for experimentation with limited computational resources.
